# 01 — 风格样板

**What to build:** 在 Gemini 网页版里生成一张风格样板图：蓝莓射手、菠萝炸弹、柠檬酸汁三个 Lv1 角色放在一起，纯品红背景。用户确认画风后，这张图和它的提示词就是后续所有素材的风格基准。这是一个需要用户确认的检查点。

参考 spec：`../spec.md` 的"原创性""美术规格""生成流程"。

**Blocked by:** None — can start immediately（前提：用户已在 Chrome 里登录 Gemini，允许 Claude 扩展访问 gemini.google.com，并接受 Google 对生成图片的使用条款）

**Status:** ready-for-human

- [ ] 在 `.gitignore` 加入原图目录（`art/fruit/raw/`）；新建提示词记录 `art/fruit/prompts.md`
- [ ] 通过 Chrome 扩展打开 Gemini，新开一个专用对话（记下对话链接，后续素材都在这个对话里生成）
- [ ] 写提示词：原创 Q 版水果角色，画风按 spec 描述，纯品红 #FF00FF 背景，三个角色分开、不互相遮挡；不出现任何既有作品的名称
- [ ] 生成样板，下载到原图目录；把提示词、日期、对话链接记进提示词记录
- [ ] 用 ImageMagick 对样板做一次去背试验，确认纯品红背景能干净地去掉（为 02 号工单验证可行性）
- [ ] 把样板和去背后的结果给用户看。用户不满意就按反馈改提示词重生成，每一轮都记录。**用户明确确认后**，才把本 ticket 标为 done
- [ ] 在 ticket 评论里记录：最终提示词、确认的画风要点（描边粗细、配色、视角），以及免费额度的使用情况
