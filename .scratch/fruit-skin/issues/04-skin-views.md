# 04 — 实现水果皮肤

**What to build:** 用 03 生成的图集，把 fruit 皮肤做完整：

- 地图：草地、泥土小路、土坑
- 塔：按等级换帧，开火和升级有动画
- 敌人：翻转朝向、弹跳、闪白、酸汁减速效果
- 子弹和果汁配色的特效
- 果园配色的 Theme tokens

只新增 Skin 和资源，不改其他层。

参考 spec：`../spec.md` 的"fruit 皮肤""不变的部分"，以及 `docs/adr/0002-skins-own-tower-level-appearance.md`。

**Blocked by:** 02 — 素材生产线与皮肤骨架；03 — 生成全部素材

**Status:** ready-for-agent

- [ ] 地图：草地纹理平铺铺满背景；路径的几何形状不变，填充改为泥土纹理；格子画土坑图，鼠标悬停时提亮；建造射程预览用代码画
- [ ] 塔：每个 (kind, level) 一帧，`sync` 发现等级变化时换帧；开火时挤压一下；升级时弹一下并有金色闪光；缺帧时报 `console.error`
- [ ] 敌人：
  - 不旋转；往左走时翻转，竖直路段保持之前的朝向
  - 走路时上下弹跳，频率随速度变化
  - 被打中时闪白（用着色或叠加实现），保留血条
  - 被减速时显示黄绿色的酸汁环，并叠一层淡黄绿色
  - 缺帧时报 `console.error`
- [ ] 子弹：按塔种用对应的帧
- [ ] 特效（用代码画）：
  - 命中和溅射：对应塔的果汁色
  - 击杀：汁滴或叶片散开
  - 卖出：保持"收缩 + 金币飘字"
- [ ] Theme tokens：温暖的果园色调；确认 HUD、塔面板、射程圈、警示色在草地背景上都清楚
- [ ] 缺帧检测：临时删掉图集里的一帧，确认对应的 story 失败；验证完恢复
- [ ] Shots：用 fruit 皮肤截图，覆盖 spec 列出的 story（带和不带 Debug overlay），逐张看过
- [ ] 扩展性检查：在评论里列出改动了哪些文件；如果超出"新 Skin + 资源 + 必要的生产线和截图脚本"，说明原因（这是对 ADR-0002 的检验）
- [ ] `pnpm typecheck && pnpm lint && pnpm test` 通过
