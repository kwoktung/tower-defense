# 05 — 基础塔攻击、击杀奖励与胜利

**What to build:** basic 塔自动攻击射程内走得最远的敌人，子弹追踪飞行，命中后造成伤害。敌人被打死后玩家获得金币，清完全部 3 波时判胜并显示胜利浮层。做完这张，游戏已经可以从头玩到输或赢。

参考 spec：`../spec.md`，包括"Simulation"的规则（选目标、子弹、击杀、判胜）和"渲染与皮肤"的事件特效部分。
