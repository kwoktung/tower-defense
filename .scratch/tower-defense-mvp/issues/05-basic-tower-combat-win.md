## Comments

- 2026-10-04 完成。
  - **验证**：
    - 40 个单元测试、18 个 story 冒烟测试全部通过。
    - 在 dev 里造 2 座塔打第 1 波：开火 33 次，击杀全部 8 个敌人，金币从 20 涨到 60，没有漏怪。
    - 把波次跳到最后一波并清场后判胜，胜利浮层出现，"重来"可用。
    - 看过 36 张截图。
  - **通关检查**：我写了一个临时的无界面测试，用贪心策略打完整局（跑完已删除）。
    - 有钱就造塔：满血胜利。
    - 只在最差的 2 个 Slot 各造一座塔：也能满血胜利。
    - 一座不造：第 2 波输。
    - 结论是能从头玩到胜利，只是**目前偏简单**。数值平衡不在 MVP 范围内。
  - **规则细节**：
    - 每个 tick 的顺序是：塔瞄准并开火 → 子弹移动和命中 → 敌人移动和漏怪 → 出怪 → 判定。所以塔是按敌人在这个 tick 开始时的位置瞄准的。
    - 射程判定包含边界：距离 ≤ 射程就算在范围内。
    - 冷却：开火后要等 `cooldownSec × 60` 个 tick 才能再开火。
  - **和 spec 不一致的地方**：
    - **事件的字段比 spec 写的多**：`towerFired` 带上了 `targetId`；`enemyKilled` 带上了 `kind` 和坐标 `x`、`y`。因为击杀特效出现时，敌人的视图已经销毁，皮肤需要从事件里拿到位置和种类。
    - **Skin 接口新增两个方法**：`createProjectileView`，以及 `playEffect(scene, event)`。后者负责不属于任何存活实体的一次性特效，比如击杀圈；06 的溅射爆炸也会走这里。
    - **Fixture builder 新增 `.advance(ticks)`**：可以用真实的 Simulation 把局面推进几个 tick。`basicTowerFiring` 就是用它构造"子弹在飞行中"的画面。
