# Spec: 护甲敌人、减速塔与第 1 关重做

Status: ready-for-agent

## Problem Statement

塔的升级与卖塔已经做完，但第 1 关体现不出它们的价值：

- 只建 1 座基础塔，然后一直升级，就能满血通关，还剩 184 金。
- 只建基础塔、从不升级，也能满血通关。

所以"铺塔还是升级"这个取舍对胜负没有影响。另外，开局 120 金只够建 1 座溅射塔，而它守不住第 1 波，等于这个开局一定会输。

游戏里也只有 2 种塔、2 种敌人，没有任何克制关系。敌人之间只有血量和速度不同，玩家不需要针对敌人调整阵容。

## Solution

- **护甲敌人**：每次被命中时，按固定值削减伤害，但最少造成原伤害的 20%。单发伤害低的塔打它很吃亏，玩家得升级伤害才能对付。
- **减速塔**：命中时让敌人减速，主要用来对付快速敌人；自身也有少量伤害。和其他塔一样有 3 级，Lv3 变成小范围溅射减速。
- **重做第 1 关**：大约 5 波，护甲敌人从第 3 波开始出现；同时调整开局金币和溅射塔造价。验收标准是：单一打法会输，混合阵容加上针对性升级能赢。

## User Stories

### 玩家

1. 作为玩家，我希望遇到一种带护甲的敌人，并且一眼就能认出它，这样我知道该换打法了。
2. 作为玩家，我希望低伤害的塔打护甲敌人明显吃亏，这样升级伤害就成了一个有意义的选择。
3. 作为玩家，我希望低伤害的塔打护甲敌人时仍然有一点效果，这样不会因为阵容不对就完全卡死。
4. 作为玩家，我希望护甲敌人走得慢、血更厚、给的金币更多，漏过时扣更多生命，这样它是一个值得专门应对的威胁。
5. 作为玩家，我希望有一种减速塔，命中的敌人会变慢一段时间，这样快速敌人会在我的射程里待得更久。
6. 作为玩家，我希望一眼就能看出哪些敌人正在被减速，这样我能判断减速塔放得对不对。
7. 作为玩家，我希望多座减速塔打同一个敌人时，减速效果取最强的一个并刷新持续时间，而不是叠到让敌人停下，这样规则好理解。
8. 作为玩家，我希望减速塔对护甲敌人照样能减速，即使伤害被护甲挡掉了大半，这样两种新内容可以搭配使用。
9. 作为玩家，我希望减速塔自己也有一点伤害，这样开局只放一座减速塔时它也不是完全没用。
10. 作为玩家，我希望减速塔也能升级，升级后减速更强、持续更久、射程更远，满级时变成小范围溅射减速，这样它和其他塔一样有成长空间。
11. 作为玩家，我希望减速塔在建造栏里和其他塔一起出现，并显示名称和造价。
12. 作为玩家，我希望减速塔的外形和颜色与基础塔、溅射塔明显不同，这样不会搞混。
13. 作为玩家，我希望选中减速塔时，面板上能看到当前和下一级的减速比例与持续时间，这样我能判断升级值不值。
14. 作为玩家，我希望第 1 关大约有 5 波、难度逐步上升，护甲敌人从第 3 波开始出现，这样我有时间先熟悉基础玩法。
15. 作为玩家，我希望"只建 1 座塔、一直升级"这种偷懒打法过不了关，这样我需要真正思考阵容。
16. 作为玩家，我希望"只建塔、从不升级"也过得很勉强，这样升级系统有存在的意义。
17. 作为玩家，我希望用混合阵容加针对性升级能稳定通关，剩下大部分生命，这样动脑筋有回报。
18. 作为玩家，我希望开局只建溅射塔至少能守住第 1 波，这样不会有一开局就注定失败的选择。

### 开发者 / 皮肤作者

19. 作为开发者，我希望护甲和减速的规则都只在 Simulation 里实现，并能通过公开 API 和 Fixture 测试，这样规则有单一出处。
20. 作为开发者，我希望减速写成"命中时附带的效果"，和攻击方式（单体、溅射）分开配置，这样以后任何塔都能组合减速。
21. 作为开发者，我希望现有敌人不需要写护甲字段（默认 0），这样单位目录的改动最小。
22. 作为开发者，我希望在 Debug overlay 里看到每个敌人的护甲值和剩余减速时间，这样调试数值时不用猜。
23. 作为开发者，我希望 `pnpm balance` 能用混合阵容、带减速塔等打法玩第 1 关，并对照验收标准输出结果，这样调关卡数值有依据。
24. 作为皮肤作者，我希望 Skin 漏画某个敌人种类时会报 `console.error`，story 冒烟测试会因此失败，这样换美术时不会漏掉护甲敌人。
25. 作为皮肤作者，我希望"被减速"的外观由敌人自己的 view 根据状态绘制，这样我只需要在一个地方表达它。

## Implementation Decisions

### 单位目录

- **敌人**新增可选的护甲值，默认 0。现有的 normal、fast 不用改数据。
- **新敌人种类 `armored`**：护甲 6，血量 60，速度 48，击杀奖励 10，漏过扣 2 条命。
- **塔的每一级**新增一个可选的减速字段，包含减速比例和持续秒数，表示"命中时附带减速"。它和攻击方式（单体、溅射）互相独立，可以随意组合。
- **新塔种 `slow`**（减速塔），3 级，初始数值如下（第 3 张工单再校准）：

  | 级 | 费用 | 射程 | 伤害 | 冷却 | 减速比例 | 持续 | 攻击方式 |
  |---|---|---|---|---|---|---|---|
  | 1 | 60 | 128 | 3 | 1.0s | 40% | 2s | 单体 |
  | 2 | +45 | 136 | 4 | 1.0s | 50% | 2.5s | 单体 |
  | 3 | +80 | 144 | 5 | 1.0s | 55% | 2.5s | 溅射，半径 40 |

- 第 1 关的波次、开局金币和溅射塔造价，由第 3 张工单按验收标准调整。

### Simulation 规则

- **护甲**：每次命中对每个受击敌人分别计算，实际伤害 = max(伤害 − 护甲, 伤害 × 20%)。不取整，血量本来就允许小数。溅射命中时，每个被波及的敌人各自扣自己的护甲。
- **减速**：
  - 子弹命中时，对每个受击敌人施加减速：单体攻击只作用于目标，溅射作用于范围内的所有敌人。
  - 减速和伤害各自独立：伤害被护甲削减多少都不影响减速；敌人在这次命中里死了，就不再处理它的减速。
  - 子弹已经记录了开火时的塔等级，减速参数也按这个等级查。
- **不叠加**：如果新的减速比例 ≥ 敌人当前的减速比例，就用新的减速替换，并重置持续时间；如果比当前的弱，就忽略。
- **移动**：敌人每个 tick 前进"速度 × (1 − 当前减速比例)"。减速剩余 tick 每个 tick 减 1，到 0 时清除。
- **数据结构**：敌人身上只加一个可空的减速状态（比例、剩余 tick 数），不做通用的状态效果列表。以后如果出现第二种状态效果（例如道具系统），再考虑泛化。
- **不新增 SimEvent**：被减速是持续状态，渲染层每帧从快照里读。现有的"敌人受伤"事件，其伤害值改为护甲削减后的实际伤害。

### 渲染与皮肤

- Polygon 皮肤：
  - 护甲敌人是深红色、更大、更方正的八边形，外面一圈灰色描边表示护甲。
  - 被减速的敌人身上叠一层冰蓝色效果，由敌人 view 每帧根据快照里的减速状态绘制或隐藏。
  - 减速塔是紫色或靛蓝色的菱形，按等级变化的规则和现有塔一致（ADR-0002）。
  - 减速塔的子弹是淡蓝色。
- 和塔一样，Polygon 皮肤的敌人 view 遇到不认识的敌人种类时，画回退外形并报 `console.error`。现有的"未知种类被击杀"story 只测击杀光环的回退颜色，不创建敌人 view，所以不受影响。
- 塔面板的属性列表新增"减速"一行，格式类似"40% · 2秒"，并显示下一级的值；没有减速的塔不显示这一行。
- Debug overlay 为每个敌人加上护甲值（大于 0 时）和剩余减速秒数（被减速时）。

### 平衡报告

`pnpm balance` 要扩展：
- 新增"混合阵容加针对性升级"和"带减速塔"的脚本打法，保留现有的打法。
- 报告里对每种打法标明是否满足验收标准：
  - 1 座塔一路升级会输。
  - 只建塔不升级会输，或者剩余生命很少。
  - 混合阵容能赢，而且剩余大部分生命。
  - 只用溅射塔能守住第 1 波。
- 它仍然是报告，不放进 `pnpm test`。

### 文档

- CONTEXT.md 新增：
  - **Armor**：每次命中按固定值减伤，最少造成原伤害的 20%。
  - **Slow**：命中时附带，不叠加，取最强的一个并刷新持续时间。
- 在 Enemy 条目里补上 `armored`，在 Tower 条目里补上 `slow`。
- 不新写 ADR。

## Testing Decisions

- **好的测试**：只通过 Simulation 的公开 API 观察行为，用 Fixture 构造初始状态；数值从单位目录读取，不写死，这样以后调数值不会让规则测试失败。不测试内部系统函数，也不测试渲染。
- **规则测试**（参考现有的 Simulation 测试和升级、卖塔测试）至少覆盖：
  - 护甲削减后的伤害；保底 20% 生效的情况（伤害 ≤ 护甲）；护甲为 0 的敌人不受影响。
  - 溅射命中时，每个被波及的敌人各自扣自己的护甲。
  - 命中后敌人被减速：之后每个 tick 的前进距离按比例变慢，持续时间到了恢复原速。
  - 更强的减速会替换当前的减速并刷新时间；更弱的被忽略；同样强的会刷新时间。
  - 减速对护甲敌人照样生效；这次命中打死敌人时不报错。
  - 子弹在飞行途中，它的塔被升级或卖掉时，减速参数仍按开火时的等级计算。
  - 减速塔 Lv3 的溅射对范围内所有敌人都施加减速。
- **视觉**：story 冒烟测试（不能有 `console.error`）加上 Shots。新增：
  - 护甲敌人的 story。
  - 被减速敌人的 story。
  - 减速塔各等级的 story（并加入现有的"所有塔种 × 所有等级"验收页）。
  - 减速塔面板的 story。
  - 一个"减速塔对付快速敌人、混合阵容对付护甲敌人"的 Scenario，用 Shot 时间线观察。
- **关卡**：用 `pnpm balance` 的报告验收，不写成断言。

## Out of Scope

- 通用的状态效果系统（冰冻、易伤、持续伤害等）。留给道具系统的讨论。
- 护甲被挡伤害时的专门命中特效、伤害数字飘字。
- 新关卡、选关界面（路线图第 5 项）。
- 提前叫下一波换奖励（路线图第 3 项）。
- 塔的目标策略切换，例如"优先打护甲敌人"。
- 减速塔的光环模式。
- 精灵图皮肤本身。
